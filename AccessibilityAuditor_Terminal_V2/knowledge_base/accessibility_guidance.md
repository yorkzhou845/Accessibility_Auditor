# General PDF Accessibility Review Guidance

This file contains original, generic guidance for demonstrating local retrieval. It is not a substitute for an applicable accessibility standard, legal advice, or human review.

## Alternative text

Meaningful images should have concise text alternatives that communicate the same essential purpose. Decorative images generally should not create unnecessary announcements for assistive technology. Text embedded in an image may need to be represented as actual text or included in an alternative when it is essential to understanding the content.

## Heading structure

Headings should describe sections and form a logical hierarchy. Visual size alone does not prove that text is a heading. Reviewers should distinguish true headings from running headers, footers, buttons, list items, and emphasized body text.

## Tables

Data tables should preserve row and column relationships and identify headers in a way assistive technology can interpret. A concise description can help explain a complex table, but it does not replace correct table structure, header associations, or accurate cell content.

## Human review

Model-generated suggestions can be incomplete or incorrect. A qualified reviewer should inspect the source PDF, verify each proposed change, apply approved remediation with an appropriate tool, and retest the resulting document.
