# Removed Files Summary

The exact original file-name audit is kept outside this public repository because workplace document names can reveal internal subjects. The sanitized package excluded the following categories:

- All workplace PDF inputs and converted copies
- All matching workplace failure reports
- All generated JSON analysis results
- All rendered PDF pages and cropped images
- All bundled input and converted-data ZIP archives
- Two top-level monolithic Python prototypes
- One duplicate monolithic source copy inside the modular folder
- All compiled `.pyc` files and `__pycache__` directories
- The original README and entry point, which were replaced with public setup documentation and a configurable CLI
- Original configuration, Ollama client, prompts, processors, router, and orchestration modules, which were rewritten or sanitized

A total of 139 original files were reviewed. Of those, 124 were excluded entirely and 15 were retained only as the basis for sanitized or reworked files.
