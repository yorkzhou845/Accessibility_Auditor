# Description: 
This is the cleaned code for the deployed Accessibility Auditor for Texas Tech University Health Sciences Center (TTUHSC).
AI-assisted automated PDF accessibility remediation application secured by TTUHSC using .NET Blazor Server, Python scripts, & iTextSharp to generate image alt text & table summaries, & produce remediated PDFs with compliance reports; applicable to 1M+ documents.
